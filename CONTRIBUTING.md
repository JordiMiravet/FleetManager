# Contributing

Thank you for your interest in Fleet Manager.

Fleet Manager is a personal portfolio project and is not offered as open-source software. Contributions are not accepted without prior agreement from the project author.

## Reporting Issues

Bug reports and improvement suggestions are welcome. Please open an issue in the [GitHub repository](https://github.com/JordiMiravet/FleetManager/issues).

When reporting an issue, provide a clear description of the problem or suggestion and include reproduction steps when applicable.

## Proposing Changes

Before implementing a code change, open an issue to discuss the proposal with the project author.

Pull requests must be agreed upon beforehand and should follow the project's development conventions.

See the [Development Workflow](docs/development-workflow.md) guide for branch naming, commit messages, task organization, and pull request requirements.
