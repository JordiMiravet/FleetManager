# Security Policy

## Overview

Fleet Manager is a personal portfolio project developed for demonstration, educational, and professional evaluation purposes.

Security is an important consideration, particularly in areas involving authentication, user data, vehicle sharing, access permissions, and API communication.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately rather than disclosing it publicly through a GitHub issue or pull request.

When reporting a vulnerability, please include:

- A clear description of the issue and its potential impact.
- The affected component or functionality (`frontend/`, `backend/`, or project configuration).
- Steps to reproduce the issue, including a proof of concept when appropriate.
- Any relevant logs or screenshots, ensuring that they do not contain passwords, tokens, personal information, or other sensitive data.

Please avoid accessing, modifying, or disclosing other users' data while investigating a potential vulnerability.

For private reports, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository owner privately through an available communication channel.

## Response and Disclosure

Reports will be reviewed on a best-effort basis. As this is a personal project, there is no guaranteed response time or commitment to provide a fix.

Please allow reasonable time for an issue to be assessed and, where appropriate, addressed before publicly disclosing technical details.

## Scope

Security reports may concern, among other things:

- Authentication and session handling.
- Authorization and access control, including vehicle sharing and invitations.
- API endpoints and backend validation.
- Exposure of secrets, credentials, or sensitive configuration.
- Dependencies and application security vulnerabilities.

## Security Limitations

Fleet Manager is a portfolio project and is not intended to guarantee production-grade security or availability.

Users should not submit real credentials, sensitive personal information, or production data to demonstration environments.
